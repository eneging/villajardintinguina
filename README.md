# EP Villa Jardín — Ica

Sitio web y plataforma de gestión para el colegio inicial y guardería **EP Villa Jardín** (Ica, Perú).

**Stack:** Laravel 12 · Inertia.js · React + TypeScript · Tailwind · MySQL — pensado para desplegarse en un **hosting compartido** (cPanel).

- Arquitectura y plan por fases: [`docs/ARQUITECTURA.md`](docs/ARQUITECTURA.md)
